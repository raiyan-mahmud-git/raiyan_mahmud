DocuMind, document Q&A that runs locally

Python, FastAPI, Chroma, SQLite, sentence-transformers, Docker

A local-first system for asking questions about your own documents. It reads PDFs, images, Markdown and text, runs OCR on scanned pages, and finds the passages that answer a question with page citations. It can optionally draft an answer with an LLM, which is off by default. It runs as a web app, a command-line tool and a REST API, with a Docker Compose setup.

Evaluation note. On a hand-written set of 18 questions, adding a cross-encoder reranker raised Recall@1 from 0.944 to 1.000. The set is tiny, so treat it as a working example of the evaluation method, not a benchmark. The live page is a showcase with sample text; the full app runs on your own machine.

Flo, a personal finance tracker

Vanilla JavaScript, HTML5, CSS3, PWA

A modular finance tracker with no backend, accounts or tracking. You track transactions, manage budgets and savings goals, visualize your spending, and keep working offline thanks to PWA support.

Privacy note. Data stays in your browser's localStorage on your own device. It is not encrypted and is lost if you clear site data, so this is a learning project, not a place for sensitive financial details.

Takeaway. Managing app state and persistence entirely in the browser with the LocalStorage API, with no backend.

TinyDL, deep learning from scratch

Inspired by Andrej Karpathy's micrograd

Python, NumPy, JavaScript

A small neural-network library with reverse-mode automatic differentiation, written with NumPy as its only dependency and no deep-learning framework. It has vectorised tensors with broadcasting, and it trains a 784-128-64-10 network with Adam on MNIST, which reaches 97.34% ± 0.23 test accuracy (mean ± standard deviation over 5 seeds, 10,000 test images). Gradient checks and optional PyTorch comparison tests check its correctness. Experiment scripts compare optimizers, dropout and initialization.

The browser demo runs a separate checkpoint trained with augmentation, which has no reported test score, and hand-drawn digits differ from MNIST. Treat the demo as an illustration, not a benchmark.
